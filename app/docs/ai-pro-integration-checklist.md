# AI Pro 연동 확인 목록

사내 AI Pro를 이 앱의 LLM 제공자로 붙이기 위해 확인해야 할 항목입니다.
현재 구현은 `backend/src/services/llm/aiProProvider.ts`에 있고, **요청/응답 형식은 추정값**이라
아래 1~4번 답을 받으면 그대로 맞춰 수정하면 됩니다.

작성 시점 기준 앱 상태: `LLM_PROVIDER=disabled`(기본값)이라 AI를 전혀 호출하지 않습니다.
아래가 확정되기 전까지 운영에 영향이 없습니다.

---

## 반드시 필요한 것 (이거 없으면 붙일 수 없음)

### 1. 엔드포인트

- 호출 URL 전체 (예: `https://aipro.___.samsung.net/v1/chat/completions`)
- HTTP 메서드 (POST로 가정하고 있습니다)
- 사내망에서만 접근 가능한가요? VPN이 필요한가요?
  - → 개발 PC에서 접근 불가하면 개발/시연 환경 구성이 달라집니다

### 2. 인증

- 인증 방식: API Key / OAuth 토큰 / 사번 기반 / 기타
- **헤더 이름과 형식**을 정확히 알려주세요
  - 예: `Authorization: Bearer <token>` 인지, `X-API-Key: <key>` 인지
- 키 발급 방법과 만료 주기
- 키가 개인 단위인가요, 시스템/서비스 단위인가요?
  - → 서버가 상시 호출해야 하므로 개인 키는 부적합할 수 있습니다

### 3. 요청 형식

가장 중요합니다. 아래 둘 중 어느 쪽인지, 아니면 제3의 형식인지 알려주세요.

**(A) OpenAI 호환** — 현재 코드가 가정하고 있는 형식
```json
{
  "model": "...",
  "max_tokens": 4000,
  "messages": [
    { "role": "system", "content": "지시문" },
    { "role": "user", "content": "실제 요청" }
  ]
}
```

**(B) Anthropic 호환** — 사내에서 Claude를 쓴다면 이쪽일 가능성
```json
{
  "model": "...",
  "max_tokens": 4000,
  "system": "지시문",
  "messages": [{ "role": "user", "content": "실제 요청" }]
}
```

### 4. 응답 형식

**(A) OpenAI 호환**: `choices[0].message.content` 에 텍스트
**(B) Anthropic 호환**: `content[0].text` 에 텍스트

실제 응답 JSON 예시를 하나 받아오시면 가장 확실합니다.

### 5. 모델 식별자

- 사용 가능한 모델 이름 문자열 (예: `claude-sonnet-4-5`, `gpt-4o`, `aipro-standard` 등)
- 여러 개면 각각의 용도/성능 차이

---

## 기능에 영향을 주는 것

### 6. 구조화 출력(JSON) 지원 여부

서술형 지원서 심사 기능은 **점수와 판단 근거를 정해진 JSON 형식으로** 받아야 합니다.

- `response_format` 또는 `json_schema` 파라미터를 지원하나요?
- 지원하지 않으면: 프롬프트로 JSON을 요청하고 앱이 파싱합니다
  (이미 그렇게 대비해뒀지만, 실패율이 올라갈 수 있습니다)

### 7. 제한 사항

- 요청당 최대 토큰 / 최대 입력 길이
- 분당·일당 호출 횟수 제한
- 타임아웃 (긴 응답이 잘리지 않는지)

## 거버넌스·개인정보 (AI Summit 심사 항목과 직결)

### 8. 데이터 취급 정책

이 앱은 AI에 **직원이 작성한 지원 사유 텍스트**와 **이름**을 보냅니다.
저장하는 개인정보는 이름·이메일·부서뿐이며, **사번은 저장하지 않습니다.**

- AI Pro에 개인정보가 포함된 텍스트를 보내도 되나요? 제약이 있나요?
- 전송된 데이터가 **학습에 사용되나요?**
- 로그·프롬프트 **보관 기간**은 어떻게 되나요?
- 별도 승인 절차나 신청서가 필요한가요?

### 9. 감사·추적

- 호출 이력이 사내에 기록되나요? 어디서 조회하나요?
- 앱 쪽에서 남겨야 할 식별자(요청 ID 등)가 있나요?
  - → 이 앱은 AI 판단 근거를 자체 감사로그에 남기고 있어, 사내 로그와 연결할 키가 있으면 좋습니다

## 확인 후 할 일

답변을 받으면 수정할 파일은 하나입니다:

```
backend/src/services/llm/aiProProvider.ts
```

그리고 `backend/.env`에 설정:

```
LLM_PROVIDER=ai_pro
AI_PRO_API_URL=<1번 답변>
AI_PRO_API_TOKEN=<2번 답변>
LLM_MODEL=<5번 답변>
```

동작 확인:

```bash
curl -s http://localhost:3000/api/v1/ai-settings
# → {"provider":"ai_pro","configured":true,...} 이면 설정 성공
```

이후 앱의 **조직 설정 → AI 기능**에서 기능별로 켜면 됩니다.
